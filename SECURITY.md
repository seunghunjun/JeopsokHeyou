# Security Policy

JeopsokHeyou is an SSH/SFTP client, so security reports are taken seriously.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's private vulnerability reporting instead:
Repository → **Security** → **Report a vulnerability**.

Please include:

- A description of the issue and its impact
- Steps to reproduce (use placeholder hosts such as `example.com`)
- The JeopsokHeyou version and your OS (Windows or macOS) version

Never include real passwords, private keys, tokens or internal server
addresses in a report.

## Supported versions

Only the latest release receives security fixes.
